# POPUPS · Portfolio

Portfolio web de POPUPS.

## Verlo localmente

Abrir `index.html` en el navegador manteniendo las carpetas `assets`, `appi`, `bondi`, `mis-sellos`, `mi-entrenador`, `oficina-virtual`, `mi-amp` y `anton` junto a los archivos HTML.

## Publicación

Este repositorio está preparado para GitHub Pages. Las URLs previstas son:

- Portfolio principal: https://somospopups.github.io/Portfolio/
- Caso APPI: https://somospopups.github.io/Portfolio/appi/
- Caso Bondi: https://somospopups.github.io/Portfolio/bondi/
- Caso Mis Sellos: https://somospopups.github.io/Portfolio/mis-sellos/
- Caso Mi Entrenador: https://somospopups.github.io/Portfolio/mi-entrenador/
- Landing Oficina Virtual: https://somospopups.github.io/Portfolio/oficina-virtual/
- Caso MI AMP: https://somospopups.github.io/Portfolio/mi-amp/
- Caso Antón · Cocina de Barrio: https://somospopups.github.io/Portfolio/anton/

La activación de GitHub Pages se realiza desde Settings → Pages del repositorio, usando la rama `main` y la carpeta `/ (root)`.
