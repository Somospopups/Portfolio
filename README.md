# POPUPS · Portfolio

Portfolio web de POPUPS.

## Verlo localmente

Abrir `index.html` en el navegador manteniendo la carpeta `assets` junto a los archivos HTML.

## Publicación

Este repositorio está preparado para GitHub Pages. La URL prevista es:

https://somospopups.github.io/Portfolio/

La activación de GitHub Pages se realiza desde Settings → Pages del repositorio, usando la rama `main` y la carpeta `/ (root)`.
